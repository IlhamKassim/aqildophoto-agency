# 03 — Package & Add-on listing

**What to build:** An Approved Photographer can create fixed-price Packages and optional Add-ons that Students will later browse and select from.

**Blocked by:** 01 — Photographer registration & approval

**Status:** ready-for-agent

- [ ] Only a Photographer with Photographer Status = Approved can create a Package
- [ ] A Package has a fixed price and description, known upfront
- [ ] A Photographer can attach one or more Add-ons to their Packages, each with its own fixed price
- [ ] A Pending or Rejected Photographer's attempt to create a Package is refused
