# 04 — Photographer opt-in & Time Slot definition

**What to build:** An Approved Photographer can opt in to a specific Convocation Event and define the discrete, bookable Time Slots they're offering for that event.

**Blocked by:** 01 — Photographer registration & approval, 02 — Convocation Event creation

**Status:** ready-for-agent

- [ ] Only an Approved Photographer can opt in to a Convocation Event
- [ ] Opting in to a Convocation Event is a distinct, explicit action — not inferred from general/passive calendar availability
- [ ] A Photographer can define one or more discrete Time Slots within an event they've opted into
- [ ] Time Slots start in an "open" state
